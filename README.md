# 《王国保卫》C++ 版（EasyX）

网页原作 `王国保卫战4.html` 的完整 C++ 移植版，用于 C++ 课程作业。
使用 **EasyX 图形库 + Visual Studio**，带窗口、鼠标交互和卡通渲染，玩法与数值完整复刻原作。

---

## 一、环境准备（只需一次）

### 1. 安装 EasyX 图形库

1. 打开 EasyX 官网：<https://easyx.cn/>
2. 点击「下载」→ 运行安装包，安装时勾选你的 Visual Studio 版本（支持 VS2015～VS2026）。
3. 安装完成后，EasyX 会自动把 `graphics.h` 等头文件放入 VS 的 include 目录，无需手动配置。

> 如果安装后仍找不到 `graphics.h`：确认安装时选中的 VS 版本与打开项目的版本一致，重新安装即可。

### 2. 打开项目

双击 `KingdomRushCpp.sln`，或新建「空项目」后把目录下的
`main.cpp`、`Game.cpp`、`Renderer.cpp` 加入「源文件」，
`Config.h`、`Game.h`、`Renderer.h` 加入「头文件」。

### 3. 编译运行

- 解决方案平台选 **x64**（推荐）或 x86 均可。
- 按 `F5`（调试运行）或 `Ctrl+F5`（直接运行）。
- 项目已启用 **Unicode 字符集**，源码带 UTF-8 BOM，中文可正常显示。

## 二、操作说明

| 操作 | 效果 |
|------|------|
| 点击左侧「建造塔」卡片 | 选中塔类型，再点击地图空地建造 |
| 点击地图上的已建塔 | 打开操作面板，可升级 / 出售 |
| 点击右侧「英雄技能」卡片 → 点击地图 | 在指定位置释放技能 |
| 顶部「开始第 N 波」 | 手动开启下一波敌人 |
| 顶部「暂停 / 速度 / 重开」 | 暂停游戏、切换 1~3 倍速、重新开始 |
| **右键** / `Esc` | 取消当前选择（建造、技能、塔面板） |
| `Q` | 退出程序 |

游戏目标：守住 20 点生命，抵御全部 **15 波** 敌人（含 2 场 BOSS 战）。

## 四、代码结构（作业讲解要点）

```
KingdomRushCpp/
├── Config.h      全局配置 + 全部数值表（塔/怪/波次/技能）
├── Game.h        实体结构体 + Game 类接口（状态、实体、方法声明）
├── Game.cpp      游戏逻辑：建造升级出售、寻路与移动、伤害结算、
│                 塔攻击、士兵 AI、技能、波次、特效更新
├── Renderer.h    EasyX 渲染接口 + UI 命中区域
├── Renderer.cpp  地图预渲染、卡通绘制、特效绘制、UI 与结算界面
├── main.cpp      窗口初始化、消息循环、鼠标/键盘交互、帧时间步进
├── KingdomRushCpp.sln / .vcxproj   Visual Studio 工程文件
└── README.md     本文档
```

设计特点：
- **数据与逻辑分离**：所有可调数值集中在 `Config.h`，改数值不改逻辑。
- **实体-组件式数据**：塔、怪物、子弹、士兵均为结构体，存于 `std::vector`，用自增 id 互相引用。
- **逻辑与渲染分离**：`Game` 只负责状态推进，`Renderer` 只读状态绘制，通过 `friend` 访问内部数据。
- **离屏缓存**：静态地图预渲染到 `IMAGE`，每帧只贴一次，保证流畅。
- **双缓冲**：`BeginBatchDraw / FlushBatchDraw` 避免画面闪烁。

## 五、常见问题

- **中文显示成方框**：确认源码为 UTF-8 带 BOM，项目字符集为 Unicode（已配置好）。
- **找不到 graphics.h**：EasyX 未安装或安装时未勾选当前 VS 版本，重装 EasyX。
- **画面卡顿**：顶部「速度」切到 x1；确认用 Release 配置编译运行。
